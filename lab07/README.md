In this lab, we created code that can:
    compute the amount of money that we'll have at the end of an investment cycle
    determine how many months it will take to reach a desired goal 
    see effects of making deposits, taking taxes out every year, and only at the end
    see differences of various number of times interest is compounded 

we learned how to format strings, arithmetic, `+=`, `+-`, `**`, algorithm design, and locales
