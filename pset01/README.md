This problem set is for Homework #1

There is *functions_cardio.py*, which has various practive functions 
There is *number_guesser.py*, which is practice for writing a complete, interactive Python program
It randomly generates a number from 1 to 1000 and prompts the user to guess it. The program tells the user if their guess is too low or too high until they guess correctly, and then the guesser repeats with a new number.
