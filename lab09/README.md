In this lab, we wrote a program that simulates the tower of hanoi legend work:
    there is a tower of 64 cylinders of decreasing size 
    they have to move the tower from one rod to another rod*
        *with a third rod available for storage
    cylinders can only be moved one at a time
    they can only be moved from the top of a rod to the top of another rod
    no cylinder can be planced on a smaller cylinder 

we learning multi-way recursion, command line arguments, exceptions, raising and catching exceptions
